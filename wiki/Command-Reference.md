# Command Reference

The following commands are available through the BadApple plugin.

## Group and permission tools

- `/group` — Manage groups, permissions, and users
- `/groupmenu` — Open the rank management GUI

## Staff utilities

- `/vanish` — Toggle vanish mode in spectator mode
- `/fly` — Toggle flight for yourself or another player
- `/gamemode` — Set survival, creative, adventure, or spectator mode
- `/nickname` — Set or clear a display nickname
- `/broadcast` — Send a server-wide announcement
- `/punishmenu` — Open punishment actions menu

## Teleport system

- `/tp` — Open the staff teleport menu or teleport directly to a target
- `/tpa <player>` — Request teleport to another player/staff member
- `/tpaccept` — Accept a pending teleport request
- `/tpdeny` — Deny a pending teleport request

## Cosmetics and player systems

- `/cosmetics` — Open the cosmetic menu
- `/api [generate|rotate|revoke|status]` — Manage the external website API key
- `/badapplehelp` — Show the help menu and wiki link

## Permissions

- `badapple.group`
- `badapple.api`
- `badapple.punish`
- `badapple.vanish`
- `badapple.broadcast`
- `badapple.fly`
- `badapple.gamemode`
- `badapple.nickname`
- `badapple.cosmetics`
- `badapple.tp`

## Notes

A number of commands are GUI-driven so staff can manage groups, players, and settings without memorizing raw CLI syntax. The plugin is also built to be permission-aware and rank-aware for all of those flows.
